02Why cloud agents, and why Cognition

Local agents make engineers faster. Cloud agents add engineering capacity.

Cloud agents decouple software production from human attention. A local agent speeds up one engineer. A cloud agent runs in parallel, around the clock, triggered by events, inside enterprise guardrails. For a services firm, that turns delivery from a labor-bound business into a compute-bound one.

The company

Cognition describes itself as an applied AI lab building end-to-end software agents. It raised over $2B at a $48B valuation in September 2026 and crossed $1B in annualized run-rate revenue that month, up from $492M in May. It ranks #6 on the inaugural AI 100 from Newcomer and Bessemer (November 2026). Devin writes most of Cognition's own code.

The difference

Devin is not a coding tool. It is engineering capacity as a service, at scale. An agent workforce that compresses the time and cost of the entire software lifecycle, delivered with the change-management muscle large enterprises need to scale it.

Devin plans the work, writes the code, runs the build and tests, and opens a pull request with the evidence the team needs to review and merge it. Consultants shift from writing code to architecting, directing and assuring it.

Hard to build, harder to run at enterprise scale

Build versus buy

Every one of these firms could try to build its own agent platform. Cognition reports that a leading cloud data platform company tried and stopped when the scope overwhelmed its infrastructure team. 05Deal and measurement

Where these deals stall, how we qualify them, and how we prove value

Six stalls specific to professional services firms that we plan for from the first meeting, the MEDDPICC checklist every opportunity runs against, and the scorecard every pilot is judged on.

"We already have a Claude alliance"

Good. Devin runs Claude models, so the alliance team sees more consumption, not less. We position Devin as the governed cloud runtime that turns those licenses into delivered work, and invite the alliance lead in early.

Independence review

Auditor independence rules limit business relationships with audit clients. We bring the firm's independence office in at M1, confirm any audit relationships up front, and start with internal work and non-audit clients.

Client code and data rules

Engagement letters govern where client code can go. Devin runs in its own VM per session and can run inside the client's own cloud account, so the access plan follows the engagement, signed at M3 with the FDE lead.

A network, not one company

Each firm is a network of member firms with separate P&Ls. We land with one member firm and one practice, usually in the US, and write the path to other member firms into the first order.

Who pays is unclear

Three commercial paths: the firm buys capacity for its own engineering, builds Devin into a fixed-fee SOW as delivery cost, or co-sells to the client. We agree the path by M3 so the deal is not stuck between practice, alliance and procurement.

A director-level champion alone

Partnerships buy top-down. An offering leader or managing partner is engaged by M2, and the business case prices margin on named fixed-fee work, not seat savings. Citi's 30% cut in tech vendor spend is the risk that makes the case urgent.

MEDDPICC checklist

Updated after every call and reviewed with my manager weekly. Select a letter to flip it to the proof required before a deal counts in the forecast.

Commit ruleA deal enters commit only when the economic buyer has confirmed the metrics, the use case has met written success criteria, independence and client-data review are cleared, the paper process is dated in a mutual plan, and the champion has been tested.

How we prove value

Measure delivered output and margin, not token usage

Tokens spent, ACUs consumed and raw pull request counts are easy to game and prove nothing to a managing partner. Every pilot is scored on outcomes the practice already reports.

What we do not sell on

  • Tokens or ACUs consumed
  • Raw pull request counts
  • Headcount reduction promised before discovery

What we measure

  • Human-equivalent engineering hours delivered, the measure Devin reports for every session
  • Margin on fixed-fee work: estimated hours versus actual hours on a named workstream
  • Time to deliver against a client milestone already in the SOW
  • Spend against output: Efficiency Score and hierarchical budgets show cost by team next to results

How it expands

A paid internal pilot proves one outcome on one workstream. That result becomes the case the offering leader takes into the next pursuit, then the next practice, then the next member firm. Cognition backs it with a guarantee that Devin delivers more engineering value than it costs, and has described one customer growing from $1.5M to over $15M in eight months as Devin moved from a pilot team to the full organization.
